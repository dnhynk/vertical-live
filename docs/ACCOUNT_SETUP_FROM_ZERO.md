# Account Setup From Zero

Last updated: 2026-05-16

This is the account creation path for launching the vertical live project from nothing.

## 1. Principle

Use a dedicated Google account and a Brand Account YouTube channel. Do not run this project from a personal daily-use Google account.

Reasons:

- A Brand Account can use a channel name/photo different from the Google account identity.
- Multiple managers can be added later without sharing the primary password.
- It is cleaner for AdSense, channel ownership, and future sale/transfer decisions.

## 2. Human-Only Steps

Codex cannot create or log in to Google/YouTube accounts for you. The user must perform these steps directly.

### Step 1: Create Dedicated Google Account

- Create a new Google account for the project.
- Store recovery email and recovery phone securely.
- Enable 2-Step Verification immediately.
- Use a password manager.

Recommended naming:

- Google account display name: project/operator name, not necessarily the public channel name.
- Public channel identity should be handled through the YouTube channel/Brand Account.

Official reference:

- Google account creation: https://support.google.com/accounts/

### Step 2: Create YouTube Brand Account Channel

Create a channel with a business/brand name rather than a personal channel.

Provisional channel identity:

- Channel name: `Pokemon Pet Lab`
- Handle: `@PokemonPetLab` if available
- Format: 24/7 vertical interactive pet live
- Audience setting: Not Made for Kids

Important: because the project intends to use Pokemon directly, the public name and assets may carry trademark/copyright risk. This document records the chosen product direction, not legal clearance.

Official references:

- Create a YouTube channel: https://support.google.com/youtube/answer/1646861
- Manage YouTube channels and Brand Accounts: https://support.google.com/youtube/answer/4642409
- Manage Brand Accounts: https://support.google.com/youtube/answer/7001996

### Step 3: Verify YouTube Account

Phone verification is required before live streaming and other features.

After verification, YouTube says the account can:

- Upload videos longer than 15 minutes
- Add custom thumbnails
- Live stream
- Appeal Content ID claims

Official reference:

- Verify your YouTube account: https://support.google.com/youtube/answer/171664

### Step 4: Request / Unlock Advanced Features

Advanced features require phone verification first, then either channel history or ID/video verification.

The project should unlock advanced features early because the channel needs:

- Live streaming
- Custom thumbnails
- Higher upload and API usability
- Fewer friction points for launch operations

### Step 5: Enable Live Streaming

YouTube requires:

- No live streaming restrictions in the last 90 days
- Verified channel
- Minimum age compliance

After first enabling live streaming, YouTube may impose a waiting period before the first stream. Plan account setup before the first launch day.

Official reference:

- Get started with live streaming: https://support.google.com/youtube/answer/2474026

## 3. Initial Channel Settings

Set these before any public upload.

- Country/region: choose based on the operator/AdSense reality, not only target audience.
- Channel audience: Not Made for Kids.
- Upload defaults: category Gaming or Entertainment; language Japanese if targeting Japan.
- Comments: allow, with moderation filters.
- Live chat: enabled.
- Hold potentially inappropriate chat messages for review.
- Branding: profile image, banner, description, links.
- Basic description should explain that the stream reacts to live viewer actions.

## 4. First 7 Public Assets

The channel starts with zero history, so it needs public assets before YPP review.

Recommended first uploads:

1. 20-40 sec Short: pet wakes up and asks for help.
2. 20-40 sec Short: like makes pet react.
3. 20-40 sec Short: chat command demo.
4. 30-60 sec vertical clip: super chat / gift effect mock demo.
5. 30-60 sec vertical clip: death and revive mechanic.
6. Public livestream test: 30-60 minutes.
7. Public livestream test: 2-6 hours.

These are not just marketing; they build channel history and help prove the stream is original and interactive.

## 5. Growth Milestones

### Milestone 1: Live Streaming Ready

- Google account created
- YouTube Brand Account channel created
- Phone verified
- Advanced features started/unlocked
- Live streaming enabled
- First private/unlisted technical stream completed

### Milestone 2: Public Launch Ready

- Branding completed
- At least 3 public uploads
- 6-hour technical stream passed
- 24-hour technical stream passed
- Cloud watchdog active
- Game state persistence active

### Milestone 3: Fan-Funding Application Ready

- 500 subscribers
- 3 public uploads in last 90 days
- 3,000 valid public watch hours in last 12 months or 3 million valid public Shorts views in last 90 days
- No active strikes
- AdSense ready

### Milestone 4: Full YPP Ready

- 1,000 subscribers
- 4,000 valid public watch hours in last 12 months or 10 million valid public Shorts views in last 90 days
